About

A terminal menu for Linux. Ping a host, list open ports and scan a subnet without remembering the flags.

Menus

Internet

Pings 8.8.8.8 to check the connection, or any site or IP you type in.

ping -c 3 8.8.8.8 · ping -c 4 host

Main menu · option 1

Ports

Lists the TCP and UDP ports your machine is listening on.

ss -tuln

Main menu · option 2

Nmap

Scans a subnet for hosts, open ports, service versions and the operating system.

sudo nmap -sS -sV -O 192.168.1.0/24

Main menu · option 3

Website

Opens the author's website in your default browser.

mraz0tix-code.github.io

Main menu · option 5

Commands

Action Command
Quick connection test, 3 packets ping -c 3 8.8.8.8
Ping a site or IP, 4 packets ping -c 4 host
List listening ports ss -tuln
Scan a subnet, default 192.168.1.0/24 sudo nmap -sS -sV -O subnet

Main menu

========================================
               NetPulse
========================================
1. Check the internet connection's menu
2. Check the ports menu
3. Nmap usage mode (nmap)
4. Exit NetPulse

5. Open mraz0tix's site

Select a menu option (1-4): >

Type a number and press Enter. Every command opens in its own kitty window and stays open until you close it.

Run

$ python NetPulse.py

Needs Linux, Python 3 and kitty. Menu items call ping, ss and nmap, so install the ones you use.

The Nmap scan calls sudo. Scan only networks you own or have permission to test.
